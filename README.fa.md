## 📖 درباره‌ی پروژه

**مترجم هوشمند** یک نرم‌افزار دسکتاپ حرفه‌ای برای ترجمه‌ی متن است که با **PyQt5** ساخته شده و از کتابخانه‌ی قدرتمند **deep-translator** (API گوگل ترنسلیت) برای ارائه‌ی ترجمه‌ی سریع و دقیق بین **بیش از ۱۰۰ زبان** بهره می‌برد.

این برنامه با یک رابط کاربری شیک و مدرن طراحی شده، کاملاً **دوزبانه (فارسی / انگلیسی)** است و به‌صورت پیش‌فرض از چیدمان **راست‌به‌چپ (RTL)** پشتیبانی می‌کند — بنابراین استفاده از آن برای کاربران فارسی، عربی، عبری و انگلیسی به‌یک‌اندازه راحت است.

> 💡 چه دانش‌آموز باشی، چه مترجم، چه برنامه‌نویس یا فقط کسی که گاهی نیاز به ترجمه‌ی سریع داری و نمی‌خواهی مرورگر باز کنی — مترجم هوشمند یک تجربه‌ی سریع و بدون حواس‌پرتی روی دسکتاپ تو فراهم می‌کند.

## ✨ ویژگی‌های کلیدی

- 🌐 **بیش از ۱۰۰ زبان** — ترجمه بین تقریباً تمام زبان‌های مهم دنیا
- 🎨 **رابط کاربری مدرن** — طراحی فلَت و تمیز با پالت رنگ اختصاصی (`#0ea480`)
- 🔁 **رابط دوزبانه** — تمامی برچسب‌ها هم به فارسی و هم انگلیسی نمایش داده می‌شوند
- ↔️ **پشتیبانی کامل از RTL** — چیدمان راست‌به‌چپ بومی برای کاربران فارسی/عربی
- 🎯 **منوهای کشویی سفارشی** — `QComboBox` دست‌ساز با فلش طراحی‌شده
- ⚡ **ترجمه‌ی فوری** — قدرت‌گرفته از گوگل ترنسلیت از طریق `deep-translator`
- 📝 **نواحی متنی بزرگ** — ویرایش راحت متون طولانی
- 🛡️ **مدیریت خطا** — نمایش پیام‌های هشدار دوستانه برای مشکلات شبکه یا ورودی
- 💻 **چندسکویی (Cross-Platform)** — اجرا روی ویندوز، مک‌او‌اس و لینوکس
- 🆓 **۱۰۰٪ رایگان و متن‌باز** — بدون تبلیغ، بدون ردیابی، بدون نیاز به API Key

## 🚀 شروع به کار

### 📋 پیش‌نیازها

از نصب بودن **Python نسخه‌ی ۳.۸ یا بالاتر** مطمئن شو:

```bash
python --version
```

### 📥 نصب

۱. **کلون کردن ریپازیتوری**
   ```bash
   git clone https://github.com/samafzalidev/smart-translator-app.git
   cd smart-translator-app
   ```

۲. **(پیشنهادی) ساخت محیط مجازی**
   ```bash
   python -m venv venv
   # در ویندوز
   venv\Scripts\activate
   # در مک‌او‌اس یا لینوکس
   source venv/bin/activate
   ```

۳. **نصب کتابخانه‌های موردنیاز**
   ```bash
   pip install PyQt5 deep-translator
   ```

   یا اگر فایل `requirements.txt` موجود باشد:
   ```bash
   pip install -r requirements.txt
   ```

۴. **اجرای برنامه**
   ```bash
   python smart_translator.py
   ```
